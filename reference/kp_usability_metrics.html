Non-additive — month-close snapshots

Unique users, sessions and prompters cannot be summed (the same person appears in several months). Save the cumulative value at each month-close; between closes, current = last anchor + same-day delta ([Sep1→today] − [Sep1→prev month-end]).

Monthly routine (first days of each month)

  • For every event metric: compute the closed month alone (1st → last day) in total and, for pill metrics, DEV-only; append total − DEV to the ledger.
  • Snapshots: compute Sep 1, 2025 → month-end for unique users (1123293977), sessions, prompters (3GVbGeJsPBCb) and append as snapshot.
  • Console numbers (prompts sent, ave. prompt, lessons created): ask the product team, append.
  • Run python3 build_dashboard.py and republish.

Known limits

  • Sep 2025 returns 0 in FullStory (already expired or pre-launch); history starts Oct 2025. Cross-check: the monthly sum for queries matched the direct cumulative query to the unit (1,785), so little was lost in practice.
  • Sidebar-card highlights (130) and download users (25) are cumulative baselines, not monthly.
  • Oct 2026 is a partial month (days 1–7); the next close overwrites it with the full month.
  • Ave. prompt (2.7) is console-derived and should be refreshed against 6,041 prompts.
